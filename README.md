# Exam Studio

수학 기출 시험지를 만드는 데스크톱 앱입니다. 이 저장소는 **설치 파일과 자동 업데이트 정보만 제공**하는
배포 전용 저장소이며 개발 소스는 담고 있지 않습니다.

## 설치 안내

최신 설치 파일은 [Releases](https://github.com/PNKmath/exam-studio/releases) 페이지에서 받을 수 있습니다.
각 릴리즈 페이지에 첨부된 `.exe`(Windows) 또는 `.dmg`(macOS) 파일을 내려받아 설치하세요.

> 각 릴리즈 페이지에는 GitHub가 자동으로 만들어 붙이는 **Source code (zip / tar.gz)** 링크도 함께 있습니다.
> 이 링크는 설치용 파일이 아니므로 내려받지 마세요. 설치에는 항상 첨부된 `.exe` / `.dmg` 자산만 사용하세요.

### Windows

1. Releases 페이지에서 `Setup...exe` 파일을 내려받아 실행합니다.
2. **"Windows의 PC 보호"(SmartScreen) 경고가 뜨는 것은 정상입니다.** 이 설치 파일은 별도의 코드 서명
   인증서 없이 배포됩니다. 경고 창에서 **추가 정보** → **실행**을 눌러 계속 진행하세요.
   이 경고를 끄는 시스템 설정 변경은 필요하지 않으며, 안내하지도 않습니다 — 경고 자체가 정상 동작입니다.
3. 설치가 끝나면 프로그램이 자동으로 실행됩니다. 이후 업데이트는 앱이 자동으로 확인·설치합니다.

### macOS

1. Releases 페이지에서 `.dmg` 파일을 내려받아 엽니다.
2. 앱 아이콘을 `Applications` 폴더로 끌어다 놓습니다.
3. 처음 실행할 때는 Gatekeeper가 앱을 검사하는 동안 **화면이 수 분간 그대로 멈춰 있는 것처럼 보일 수
   있습니다.** 실측 사례에서 첫 실행 전 정체가 최대 약 6분까지 걸린 적이 있습니다. 이는 앱이 멈춘 것이
   아니라 macOS의 최초 보안 평가가 진행 중인 것이므로, 강제 종료하지 말고 기다려 주세요. 이후 실행부터는
   이 정체가 사라집니다.
4. macOS가 "확인되지 않은 개발자"라고 표시하며 실행을 막는 경우, `시스템 설정 > 개인정보 보호 및 보안`에서
   해당 앱에 대해 **열기**를 선택하면 됩니다.

## 지원 및 문의

설치나 사용 중 문제가 있으면 이 저장소의 [Issues](https://github.com/PNKmath/exam-studio/issues)에
등록해 주세요. 개발 소스는 이 저장소에 없지만 문의 채널은 계속 이 저장소에서 운영합니다.

## 회수 불가 한계

저장소를 Private/Public으로 분리하는 과정에서 되돌릴 수 없는 부분이 있습니다. 정직하게 남겨둡니다.

- 이 저장소가 Public으로 전환되기 전, 제3자가 만든 공개 fork 4개는 각자의 소유이며 전환 이후에도 계속
  공개 상태로 남습니다. 저장소 측에서 이를 회수하거나 비공개로 만들 수 없습니다.
- 저장소 전환 과정에서 기존 stars/watchers 기록은 삭제됩니다.
- 전환 이전에 이미 내려받히거나 복제된 과거 소스 코드는 이 저장소의 조치와 무관하게 회수되지 않습니다.

이 한계는 전환의 성공 조건이 아니라, 전환 이후에도 남아 있는 실제 한계로 기록합니다.
